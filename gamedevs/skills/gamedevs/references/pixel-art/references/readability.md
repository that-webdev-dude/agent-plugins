# Readability and shading

Use this note for sprite design, palette decisions or a visual critique.

- Group neighbouring pixels into intentional shapes. Stray single pixels often add noise; reserve them for meaningful features, glints or motion.
- Judge the silhouette and the large light/dark masses at intended display size before refining edges. Background detail should not compete with the character's identifying shapes.
- Start with a small shared palette. Make adjacent materials distinguishable by value as well as hue. Keep the same light direction throughout a set.
- Describe volume with coherent lit and shaded planes. Avoid placing highlights merely to follow the outline. Colour shifts across a ramp can be more useful than many almost-identical brightness steps.
- In motion, check that clusters remain understandable rather than turning into crawling isolated pixels.
